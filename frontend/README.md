# Frontend（Vue3 + ECharts）

> 此目录为前端占位，将在 v0.2 阶段开发。

## 计划功能

- 任务输入面板
- 轨迹时间线（ECharts Gantt 图）
- Token 消耗流图（ECharts Sankey）
- 失败节点高亮 + 归因展示
- 与 CrewAI / AutoGPT 的横向对比表

## 技术栈（待定）

- Vue 3 + Vite
- Element Plus / Naive UI（组件库）
- ECharts 5.x（可视化）
- Pinia（状态管理）
- Axios（HTTP）

## 启动方式（开发版）

```bash
cd frontend
npm install
npm run dev
# 默认 http://localhost:5173
```
